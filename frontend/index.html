Architecture & Security Blueprint

Frontend vs Backend vs Supabase & .env Files

This application implements clean separation between Frontend Client, Backend Proxy, and Supabase Database.

💻

Frontend (Client)

/frontend/ • frontend/.env
  • Vanilla HTML5, CSS3, ES6 JS
  • Markdown & Code Rendering
  • Calls POST /api/chat
  • Uses SUPABASE_ANON_KEY (safe for browser with RLS)
  • ❌ Never holds Gemini Key or Service Role Key

Backend (Server)

/backend/ • backend/.env
  • Node.js + Express API
  • Stores GEMINI_API_KEY
  • Stores SUPABASE_SERVICE_ROLE_KEY
  • Official @google/genai SDK
  • 🔒 True security boundary
